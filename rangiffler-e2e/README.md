# Скриншотные тесты

Для UI-тестов нужны запущенные Rangiffler (`http://localhost:3001`), auth, API и базы данных из `LocalConfig`.

Проверка аватара и карты путешествий:

```bash
./gradlew :rangiffler-e2e:test \
  --tests '*UserProfileTests' \
  --tests '*TravelsMapTests'
```

Тесты загружают аватар и фотографию через UI. Тест карты выбирает Францию, проверяет сохранённое фото после обновления страницы и сравнивает карту с эталоном. Загруженное фото удаляется после проверки.

При расхождении в Allure появляется `Screenshot diff` с expected, actual и diff. Если изменение оформления ожидаемо, перезапустите нужный тест с флагом:

```bash
./gradlew :rangiffler-e2e:test \
  --tests '*TravelsMapTests' \
  -DrewriteExpected=true
```

Флаг передаётся в тестовую JVM. Во время сравнения actual заменяет PNG-файл по пути из `@ScreenShotTest` внутри `rangiffler-e2e/src/test/resources`, например `img/expected_travels_map.png`. Исходный эталон должен существовать и читаться. Без флага файлы не изменяются; сравнение остаётся точным, без допуска. Ошибки загрузки, функциональных проверок и записи файла продолжают приводить к падению теста.

В IDE укажите `-DrewriteExpected=true` в VM options запуска теста. Поддерживаются рабочие каталоги корня репозитория и модуля `rangiffler-e2e`.

После перезаписи проверьте изменение PNG в Git и повторите запуск без флага.
